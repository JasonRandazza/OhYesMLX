## Findings

### F1 [critical] The speculative-draft probe measures with both target and draft weights resident
Where: `scripts/probe_speculative_draft.py:431-443`
Evidence: `m35, tok35 = load(TARGET_PATH)`; `m4, tok4 = load(DRAFT_PATH)`; `print(f"Draft loaded in {t_draft_load:.2f}s (Total RAM: {both_mem_mb:.1f} MB, Draft delta: +{both_mem_mb - target_mem_mb:.1f} MB)")`
Failure: this deliberately violates the harness's exactly-one-model-resident invariant; memory pressure/swap can distort speed and footprint, so this result is not a single-resident benchmark and must be explicitly reported as a dual-model workload rather than compared to ordinary single-model runs.
Fix: label and scope every comparison to the simultaneous target+draft workload; do not present its dual-resident results as a single-model harness result.

### F2 [high] Probe_grid and probe_grid_moe can declare incoherent output LOADS
Where: `scripts/probe_grid.py:41-42`; `scripts/probe_grid_moe.py:62-63`
Evidence: `row["coherent"] = coherence.is_coherent(text)[0] if text.strip() else None`; `row["verdict"] = "LOADS" if obs.ok else f"answered: {obs.error}"`
Failure: an HTTP-successful request with token salad gets verdict `LOADS`; the grid-spec decisions can include an unusable cell. Research explicitly treats these scripts as evidence for capability and grid membership.
Fix: derive LOADS from `obs.ok and coherent is True` and give incoherent/empty outputs a FAIL verdict.

### F3 [high] KV-cache and multi-turn papers publish throughput from duplicated, non-harness formulas
Where: `scripts/probe_kv_quant.py:226-239`; `scripts/probe_multiturn_sweep.py:193-207`
Evidence: `round((tokens - 1) / decode_time, 2)`; `round((decode_time / (tokens - 1)) * 1000.0, 2)`
Failure: the harness's pinned formula is `completion_tokens / (last_content_s - ttft_s)` with `itl_s = span / max(1, completion_tokens - 1)`; the scripts instead subtract one token in decode TPS and substitute zero for undefined windows. Quantized KV caches and multiturn research therefore publish systematically lower rates and fabricated zeros for invalid spans, and multi-turn means include those zeros.
Fix: call `measure.decode_tps` and `measure.itl_s` for each observation and preserve `None` outside the domain.

### F4 [high] Expert-streaming and multi-turn coherence annotations do not gate published numbers
Where: `scripts/probe_expert_streaming_35b.py:286-303,331-347`; `scripts/probe_multiturn_sweep.py:209-228,252-258`
Evidence: `r1_coherent, r1_reason = coherence.is_coherent(obs1.text)`; `"decode_tps": r1_decode_tps`; `"coherent": coherent`; `"mean_decode_tps": round(sum(decode_rates) / len(decode_rates), 2)`
Failure: incoherent or empty output is stored beside usable-looking throughput, and later expert-streaming request #2 has no coherence check. This defeats the project floor; affected 35B expert-streaming and 50-turn conversation results report metrics alongside PASS/FAIL annotations rather than suppressing the numbers.
Fix: use the measured content/reasoning text with the coherence result as a gate before counting or publishing any speed figure.

### F5 [high] Probe_native_mtp_35b computes speed over total stream duration and can substitute RSS for footprint
Where: `scripts/probe_native_mtp_35b.py:77-98,228-236`
Evidence: `out = subprocess.check_output(["ps", "-o", "rss=", "-p", str(pid)], text=True).strip()`; `gen_time_s = max(0.001, total_duration_s - ttft_s)`; `decode_tps = gen_tokens / gen_time_s if gen_tokens > 0 else 0.0`
Failure: RSS is forbidden for MLX process memory here, and total-minus-TTFT is not the harness's last-content decode window; final usage/SSE teardown contaminates the claimed MTP rates. Published native-MTP results report speed and memory from these values.
Fix: remove the RSS fallback and calculate only from content-delta timings using the harness formula; report unavailable values as unavailable.

### F6 [high] Multiturn aggregation publishes a mean across warmup/cold-start turns and does not retain raw observations
Where: `scripts/probe_multiturn_sweep.py:242-258,304-314`
Evidence: `decode_rates = [t["decode_tps"] for t in result["turns"]]`; `"mean_decode_tps": round(sum(decode_rates) / len(decode_rates), 2)`; `out_file.write_text(json.dumps(all_results, indent=2), "utf-8")`
Failure: the first turn is cold-start and subsequent turns are not plateau-warmed, yet the paper characterizes the cross-turn mean/standard deviation as stable decode behavior; only derived values plus 140-char snippets survive, so underlying samples cannot recompute it.
Fix: retain complete transport observations and separate cold/settling turns from the steady-state statistic using a declared warmup protocol.

### F7 [medium] Grid loadability outputs truncate the sample that is needed to audit the coherence verdict
Where: `scripts/probe_grid.py:39-42`; `scripts/probe_grid_moe.py:59-63`; `scripts/probe_grid_35b.py:167-180`
Evidence: `row["text"] = (text or "")[:70]`; `row["text"] = text[:70]`
Failure: if incoherence depends on a later character or a longer sample, saved/printed probe evidence cannot be rechecked; it also fails the raw-observation-retention rule. Research relies on these probes to define candidate grid cells.
Fix: persist the complete request observation and keep a separate abbreviated display field.

### F8 [medium] Expert-streaming and KV-cache scripts round undefined decode windows into numeric zero
Where: `scripts/probe_expert_streaming_35b.py:276-284,331-339`; `scripts/probe_kv_quant.py:226-239`
Evidence: `else 0.0`; `"decode_tps": r1_decode_tps`
Failure: a one-event/non-streaming response or empty output is reported as zero tok/s (and contributes to a sweep/summary), although the metric has no valid decode window; that turns missing evidence into a measured penalty.
Fix: use the harness domain check and serialize `None` when the rate/ITL is undefined.
