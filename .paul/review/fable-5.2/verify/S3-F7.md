# S3-F7 — the couldn't-start retry relaunches beside a live backend and quits the app

**Claim (one line):** after `reload()` fails with an adopted, still-running backend,
the `.couldntStart` screen's button calls `relaunch()`, which starts a second backend
instead of re-running `reload()`; the first session's `flock` makes `start()` return
`.alreadyRunning`, `alreadyRunning = true` makes the app terminate itself.

## Code path, as cited

- `app/Sources/OhYesMLX/RootView.swift:18-23` — `.couldntStart` renders
  `CouldntStartStateView` whose action is `Task { await model.relaunch() }` (line 22).
- `app/Sources/OhYesMLXKit/AppModel.swift:386-408` — `relaunch()` resets
  `backendStopped`/`backendStderrTail`/`quitAnywayOffered`/`job`, sets `screen = .launching`,
  then goes straight to `switch await launcher.start()`. It never reads, quits, or refuses
  the existing `runner`. `.alreadyRunning` maps to `alreadyRunning = true` (:401-402).
- `app/Sources/OhYesMLXKit/AppModel.swift:410-444` — `reload()` sets
  `screen = .couldntStart` on the hardware timeout (:416-429) and on an `engines()` /
  `recommendations()` throw (:432-443). `runner` is untouched on every path, and `adopt()`
  (:591-599) has already installed it.
- `app/Sources/OhYesMLXKit/BackendLauncher.swift:170-172` — `start()` returns
  `.alreadyRunning` when `acquireLock()` fails; `:260-269` — `acquireLock` is
  `open(app.lock)` + `flock(LOCK_EX | LOCK_NB)`. `LaunchSession` holds that descriptor until
  the child exits (`releaseLockIfNeeded`, `:518-528`).
- `app/Sources/OhYesMLX/OhYesMLXApp.swift:40-49` — `.onChange(of: model.alreadyRunning)`
  activates the "other instance" (here: itself, the only running instance) and calls
  `NSApp.terminate(nil)`.

The "Scan Again" variant is the same mechanism: `RootView.swift:61-64` calls
`model.reload()`, whose failure produces the same `.couldntStart` + live-runner state.

## Reproduction

Test: `app/Tests/OhYesMLXKitTests/FableS3F7Tests.swift::testRetryingFromCouldntStartDoesNotTreatTheLiveBackendAsASecondInstance`
(new file; no production code touched).

It uses the real `BackendLauncher` and the real `LaunchSession` — the only double is a
`LauncherProcess` that prints `{"port": 9, "token": "fable-s3-f7"}` and stays alive, so the
session genuinely holds `app.lock` (verified on this host that a second `flock` on a new fd
in the same process is denied: `Errno 35 Resource temporarily unavailable`). The launch
adopts the backend; nothing listens on port 9, so `reload()`'s hardware poll times out and
the screen becomes `.couldntStart` while the child is still running. The test then invokes
the screen's action (`model.relaunch()`) and asserts the retry did not mistake the app's own
backend for another instance (`alreadyRunning == false`) and did not leave the app on an
unfinished launching screen (`screen == .couldntStart`).

Command:
```
cd app && OYMLX_DEV_PYTHON=$HOME/.local/share/ohyesmlx/app-dev-venv/bin/python \
  swift test --filter FableS3F7
```

Output on the current code:
```
error: ... XCTAssertFalse failed - the retry took the app's own live backend for another instance;
OhYesMLXApp.swift:40-49 then activates it (itself) and calls NSApp.terminate, closing the retry
error: ... XCTAssertEqual failed: ("launching") is not equal to ("couldntStart") - the retry
neither re-ran reload() nor reported another failure; it left the app on a launching screen
it never completed
Executed 1 test, with 2 failures (0 unexpected) in 0.402 seconds
```

Both symptoms are exactly the finding's: `alreadyRunning` became `true` (the precondition
for `NSApp.terminate`) and `relaunch()` never reached `reload()` (screen stayed `.launching`).
