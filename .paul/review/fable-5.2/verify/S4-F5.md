1.5% gap a tie.

The summary the test builds is the shape `_run` builds: `stage_b.engine` set, `cells` holding
the reused stage-A row (`dict(top, reused=True)`, `quickbench.py:836`) beside one sibling
measured later, both `status == "PASS"` with a `decode_tps`. 72.1 − 71.0 = 1.1 tok/s;
71.0 × 0.05 = 3.55, so the gap is inside the band by a factor of three. `_best` returns the
sibling's block anyway.

The second test in the same file,
`test_best_takes_the_sibling_once_it_clears_the_band`, is the control: with 60.0 vs 70.0
(16.7%, outside the band) `_best` returns the sibling, and that test **passes**. So the
failure is the missing band, not a broken helper or a mis-shaped fixture — a fix that simply
always keeps the baseline would fail the control.

## The code path, with line numbers

1. **The band exists, once.** `TIE = canary.NOISE_FLOOR` (`quickbench.py:67`) is
   `NOISE_FLOOR = 0.05` (`canary.py:47`), Decision 131's floor. Stage A uses it in
   `_winner` (`quickbench.py:374-396`): the top PASS cell by `decode_tps` (`:389`), then
   every cell within `top["decode_tps"] * TIE` (`:393`) reported as a tie rather than ranked.
2. **Stage A records the tie.** `_run` writes `summary["stage_a"]["tie"] = tied if len(tied) > 1
   else []` (`quickbench.py:832`), after taking `top, tied = _winner(...)` at `:814`.
3. **Stage B reuses the baseline row.** `summary["stage_b"]["engine"] = top["engine"]` (`:833`)
   and `summary["stage_b"]["cells"].append(dict(top, reused=True))` (`:836`); the sibling loop
   then measures each other format on that engine and appends its own row. The baseline entry
   is a *stage-A* row: measured before stage B started, in whatever thermal state stage A had.
4. **`_best` applies no band.** `_best` (`quickbench.py:398-425`) selects `stage_b.cells`
   whenever `stage_b.engine` is set (`:408-412`), filters to `status == "PASS"` with a
   `decode_tps` (`:413-417`), and takes `max(..., key=lambda cell: cell["decode_tps"])`
   (`:419`) with no comparison to `TIE`. `_winner`'s `tied` list has no counterpart here.
5. **`stage_b` has no tie field to carry it.** The summary is initialised with
   `"stage_b": {"caveat": CAVEAT_B, "engine": None, "cells": [], "note": None}`
   (`quickbench.py:603`) — `caveat, engine, cells, note` and nothing else. `grep '"tie"'` over
   `quickbench.py` finds only the stage-a initialiser at `:600` and the assignment at `:832`.
6. **The label is persisted.** `summary["best"] = _best(...) if summary["ended"] ==
   "finished" else None` (`quickbench.py:994-996`), then `_write_summary(root / SUMMARY_NAME,

7. **It reaches the recommendations as `measured_here`.** `quickbench.latest`
   (`quickbench.py:1026-1065`) reads each finished `summary.json`, takes `payload["best"]`,

## The second half of the claim — order aliased onto format

The baseline row is measured during stage A and reused in stage B (`:836`); every sibling is
measured after it, twenty minutes later in the finding's scenario, and the harness interleaves
and cools only within a column, not across the reused row. So the stage-B comparison is not a
paired same-session measurement of baseline and sibling: the baseline's number is from an
earlier thermal state by construction. That is a real asymmetry in the comparison and the
finding's fix direction ("carry the caveat that the baseline row was measured earlier") is
consistent with it. I did not measure anything to quantify the drift — see below.

## Severity check

The finding's Medium holds. On a gap inside the band the harness persists and displays a
*preference between formats* that its own Decision 131 says it cannot resolve — and stage B is
the comparison the quick run exists for, so this is the one claim the user is shown. It is
not higher: the number it publishes (72.1 tok/s) is a real measurement of the sibling, nothing
is approximated or invented, and the failure mode is a label the user can re-run, not a wrong
figure or a lost observation. It is not lower: the label is user-facing on two surfaces
(Results "Best on your Mac", and `measured_here` on the recommendations list), it names a
winner where stage A would name a tie, and the baseline's earlier thermal state is silently
part of the comparison.
