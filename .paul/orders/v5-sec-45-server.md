# Order: security review, SERVER side, v5.0 Phase 4.5 plan 045-01 (read-only; report in your final message, no files)
Frame: `ohyesmlx app` is a stdlib `ThreadingHTTPServer` on 127.0.0.1 behind a per-launch 256-bit token printed once on stdout to the parent app (no file, no argv). Guard order: exact Host (`127.0.0.1:<port>` / `localhost:<port>`), any Origin refused, `Authorization: Bearer` compared with hmac. Actors in scope: a web page in the user's browser (incl. DNS rebinding), another process of the same user, another local account (loopback is reachable by every local user), a compromised upstream. Out of scope: root, physical access. This order carries no token and you need none.
Read at HEAD (you cannot run git): ohyesmlx/server.py (whole), quickbench.py (whole), osaurus_settings.py (whole), cli.py `_app`, `_stop`, `_stop_at_eof`, the `app` parser; runtimes.py `_engine_env`, `_run`, `_spawn`, `_resident_osaurus_pids`, `_signal_tree`, `_signal_process`, `_port_is_free`, `LOGS_DIR`; docs/interfaces.md (v5.0 sections).
Questions: (1) any request that reaches a module without passing all three guard checks, incl. HEAD/OPTIONS, malformed or duplicate headers, absolute-form request targets; (2) body and arg validation: anything other than a name string, literal true and quickbench's `osaurus` bool that reaches a module; (3) job-slot exhaustion or a job that never frees its slot; (4) per-job SSE reader count and handler-thread exhaustion, authenticated and unauthenticated; (5) shutdown with a running pip step or quickbench cell: what is left running, half-written or pinned when the 120 s wait expires or the process is SIGKILLed; (6) every place the token could leak: stdout, stderr, logs, exception text, child-process environment or inherited fds, `/proc`-style inspection; (7) the Osaurus pin/restore: races with the Osaurus app rewriting its config mid-run, a crash between pin and restore, and who recovers it; (8) every path under the repo (`config/`, `results/`) a packaged, read-only app bundle would try to write; (9) bare command names (`ps`, `open`, `sysctl`) resolved on a PATH that `_engine_env` prefixes with lab-path directories.
Do not re-report (known, dispositioned): no 401 rate limit (256-bit token); no TLS on loopback; finished jobs never pruned; an evict cannot be cancelled; UAT-001 (`fetch.downloaded` compares sizes); a pip step can outlive the 120 s shutdown wait is KNOWN, but report what state it leaves.
Report a findings table: id, file:line, actor, impact, severity (high = an in-scope actor without the token can change the machine, run code, read the user's files or delete data; medium = needs the token or a same-user process, or leaves the user's state wrong without saying so; low = defence in depth). Cite file:line only, no exploit payloads beyond what a finding needs. Say "none found" per question rather than padding. Under 800 words. Do not edit anything.
