<acceptance_criteria>
## AC-1: Names come from one place
Given `runtimes.RUNTIMES` keys `mlxlm, osaurus, omlx, optiq, vmlx, mtplx`
When `detect_all` runs
Then it returns exactly five statuses named `mlxlm, osaurus, omlx, optiq, vmlx` (mtplx excluded by D2), and `docs/interfaces.md` says `mlxlm` (resolves research §6.1)

## AC-2: Installed means a file test, not PATH
Given an injected filesystem where only `~/.omlx/bin/omlx` and `/Applications/oMLX.app` exist
When `detect_all` runs
Then oMLX is installed with a resolved real path, the other four are not, and a stale `/opt/homebrew/bin/osaurus` link with no app bundle does not count (research §6.2)

## AC-3: Versions come from files
Given fixture `Info.plist` / `_version.py` / `__init__.py` contents per engine
When `detect_all` runs
Then each version equals the fixture literal (Osaurus 0.25.28, oMLX 0.7.2, OptiQ 0.5.13, mlx-lm 0.31.3, vMLX 1.6.59), and an unreadable file gives `version: null` with `installed: true`

## AC-4: Tested-version flag
Given the harness-tested versions in one table in `engines.py`
When an installed version differs
Then the status carries `tested: false`; when it matches, `tested: true`
</acceptance_criteria>
