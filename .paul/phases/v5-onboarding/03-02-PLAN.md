<objective>
## Goal
`recommend.pick(hw, catalog, engines, free_disk) -> list[Pick]` returns the models that fit this Mac's memory and disk and can be served by an engine the user has (or could install), ranked, each with a reason string.

## Purpose
Seam S4. Honesty rule D5: "fits" is computed from RAM and disk and labelled `estimated`; speed appears only from the user's own runs (`measured_here`, filled by Phase 4, null here).

## Output
`recommend.py`, tests, one amendment to the pinned `Pick` shape.
</objective>

<acceptance_criteria>

## AC-1: Memory fit, one definition
Given `size_bytes` and `hw.model_budget_bytes`
Then `comfortable` iff size_bytes*2.0 <= budget; `tight` iff size_bytes*1.25 <= budget (else excluded); the two constants and their rationale (research §4.3: measured worst peak/weights 1.94x within a runtime; budget already holds a 2 GiB reserve) live once in recommend.py. Literals: 16 GiB Mac (budget 9,305,762,474) keeps LFM2.5-8B-A1B (4,782,228,614) out; an 8 GiB Mac (budget 3,579,139,413) keeps Qwen3.5-2B-oQ4 (1,794,528,789) out as comfortable (3.59 GB > budget) but tight (2.24 GB <= budget)

## AC-2: Disk fit
Given free disk
Then a model needs free >= size_bytes*1.2 (the largest-shard .incomplete beside finished files); excluded models carry `reason` for the UI to show; a Mac under `supported: false` gets an empty list and one explanatory item, never a pick

## AC-3: Engines
Given EngineStatus rows
Then each pick lists `engines`: installed engines in catalog `engines` for that model; when none is installed it lists the catalog engines under `install_needed: true` so the UI can say "install X first"

## AC-4: Ranking
Then order is: comfortable before tight; within that larger `params` first (a quality proxy, stated as such); starter tier before standard when both comfortable and the Mac's free disk is under 20 GiB; ties break by repo id (deterministic); the first three are flagged `start_here`

## AC-5: Reasons are deterministic text
Then `reason` is a fixed template filled with numbers ("Fits with about 4.1 GB of memory to spare; 1.7 GB download") and is tested with literals; no vendor speed claims, no M2 Max numbers

## AC-6: Shape pinned
Then `Pick` in docs/interfaces.md is amended to: model_id, title, params_b, format, size_bytes, fit ("comfortable"|"tight"), fit_basis ("estimated"), engines [str], install_needed bool, start_here bool, reason, measured_here (null here)
</acceptance_criteria>
