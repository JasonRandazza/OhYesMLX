<objective>
## Goal
`config/engines-tested.json` becomes the only place an engine's tested version (and optional lab copy) is written; `engines.TESTED_VERSIONS` loads from it; the harness starts engines from the lab copy when the manifest names one.

## Purpose
Decision 135: upstream drift (OptiQ 0.5.13 to 0.7.8, vMLX 1.6.59 to 1.6.82 on 2026-10-29) must not void published tables. Today the lab venv is reached by `export PATH=...mlx-lm-0.31.3/bin` copy-pasted into shell scripts (e.g. `scripts/run_grid.sh:16`); that is a hand-kept second definition.

## Output
Manifest file, loader in `engines.py`, one PATH-prefix definition in `runtimes.py` used by `_spawn` and `_run`, tests.
</objective>

<acceptance_criteria>

## AC-1: The manifest is the only version table
Given `config/engines-tested.json` with, per engine in ONBOARDING_ENGINES: `version`, `verified` (ISO date), `lab_path` (string|null), `canary` (object|null)
When `engines` is imported
Then `TESTED_VERSIONS` equals the manifest's versions (osaurus 0.25.28, omlx 0.7.2, optiq 0.5.13, mlxlm 0.31.3, vmlx 1.6.59), no version literal remains in `engines.py`, and a missing/invalid manifest raises a clear error naming the file

## AC-2: Manifest shape is validated
Given a manifest missing an engine, with an unknown engine, or with a non-string version
Then loading raises ValueError naming the engine and field (tests drive the loader with a path)

## AC-3: Lab path reaches the spawned engine
Given a manifest entry with `lab_path` = a bin directory
When `runtimes` builds the environment for `_spawn` and `_run`
Then that directory is prefixed to PATH (one function, `_engine_env`, the only place), entries with `lab_path: null` add nothing, and a `lab_path` that does not exist is refused with a message naming the engine

## AC-4: No behaviour change when no lab path is set
Given the shipped manifest (all `lab_path` null except mlxlm = `~/.local/share/ohyesmlx/mlx-lm-0.31.3/bin`)
Then every existing runtime start/stop/version command is byte-identical to today (the existing TODAY table in tests/test_runtimes.py must not change)

## AC-5: Detection agrees with the manifest
Given an installed engine whose version differs from the manifest
Then `tested` is false (unchanged), and the manifest `verified` date is exposed on `EngineStatus` as `verified` (pinned shape updated)
</acceptance_criteria>
