<objective>
## Goal
`ohyesmlx canary --repeat N` measures each engine's cell N times. The visits are interleaved across engines: rep 1 visits every engine, then rep 2 visits every engine, and so on. The verdict and any `--record` use the **median** of the N readings, taken per metric.

## Purpose
The 2026-11-20 runs showed a 5–10% session-to-session swing at fixed versions (`docs/research/2026-11-20-canaries-and-35b-r4.md` §2), which is wider than the 5% `NOISE_FLOOR`. Single-run baselines therefore produce false "moved" verdicts. Jason chose median-of-3 (2026-11-21).
</objective>

<acceptance_criteria>
## AC-1: repeat, interleaved, median
Given `ohyesmlx canary --yes --repeat 3 --engines a,b`
Then the cells run in the order a1 b1 a2 b2 a3 b3. Each run has its own results dir, `<stamp>-<engine>-r<k>`.
And each engine prints ONE verdict line, computed from the median decode_tps and the median ttft_p50_s of its N rows.
And `--repeat` defaults to 1, which keeps today's behaviour and output byte-for-byte. All existing canary tests stay unmodified.
And `--repeat` below 1 is refused with exit code 2.

## AC-2: what counts
Given any of an engine's N rows is not PASS
Then that engine's line is a FAIL line, naming the failing rep. Nothing is recorded for it.
And the engine is noisy when the load was above `LOAD_NOISY` around any of its reps. `--record` refuses a noisy engine unless `--allow-noisy` is passed, as today.

## AC-3: record keeps the readings
Given `--record --repeat N` and an engine that passed and was not noisy
Then the manifest gets the medians as `decode_tok_s` and `ttft_s`, as today. It also gets `runs`: the N `{decode_tok_s, ttft_s}` readings in rep order. Raw observations are never discarded.
And `--record --repeat 1` writes `runs` with one entry.
And the median is one function in canary.py, the one definition. The CLI never computes a median itself.
And the docs say what `--repeat` does, in one sentence each: the `--repeat` help text, the canary paragraph in `docs/interfaces/v5-onboarding.md`, and the README canary section. The help text recommends `--repeat 3` for `--record`.
</acceptance_criteria>
